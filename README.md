# Τάβλι στου παππού

Εφαρμογή για το πρωτάθλημα τάβλι: πρόγραμμα, σκορ, βαθμολογία και πληρωμές.

- **Online:** https://tavli-stou-pappou.vercel.app
- **Βάση:** Supabase, project `tavli-stou-pappou`
- **Δημοσίευση:** κάθε push στο `main` ανεβαίνει αυτόματα στο Vercel.

## Αρχεία

| Αρχείο | Τι κάνει |
|---|---|
| `index.html` | Η δομή της σελίδας και τα παράθυρα επεξεργασίας |
| `css/styles.css` | Εμφάνιση |
| `js/config.js` | Σύνδεση με τη βάση |
| `js/supabase.js` | Ο client της βάσης |
| `js/state.js` | Κοινή κατάσταση και βοηθητικά |
| `js/data.js` | Φόρτωση, αποθήκευση, ζωντανή ενημέρωση |
| `js/stats.js` | Υπολογισμός βαθμολογίας και πληρωμών |
| `js/schedule.js` | Αυτόματο πρόγραμμα «όλοι με όλους» |
| `js/tournaments.js` | Επιλογή, δημιουργία και ρυθμίσεις τουρνουά |
| `js/render.js` | Σχεδίαση των καρτελών |
| `js/dialogs.js` | Επεξεργασία αγώνων, αγωνιστικών, παικτών |
| `js/auth.js` | Σύνδεση γραμματείας με email |
| `js/main.js` | Εκκίνηση |

## Τουρνουά

- Οι παίκτες είναι κοινοί για όλα τα τουρνουά.
- «+ Νέο τουρνουά» (γραμματεία): όνομα, συμμετοχή €, βαθμοί, μονός/διπλός γύρος, ποιοι παίζουν. Το πρόγραμμα βγαίνει αυτόματα με κλήρωση.
- «Ρυθμίσεις τουρνουά»: αλλαγή ονόματος, συμμετοχής και βαθμών. Διαγραφή μόνο αν δεν έχει αποτελέσματα ή πληρωμές.
- Η λίστα πάνω αλλάζει τουρνουά. Από προεπιλογή ανοίγει το πιο πρόσφατο.

## Βαθμολογία

Νίκη = 1 βαθμός. Νίκη με τον αντίπαλο στο 0 = 2 βαθμοί (ορίζονται ανά τουρνουά).
Ισοβαθμία: διαφορά πόντων, μετά πόντοι υπέρ.

## Δικαιώματα

Όλοι βλέπουν χωρίς σύνδεση. Αλλαγές κάνουν μόνο τα email του πίνακα `admins` στο Supabase.

Σύνδεση γραμματείας:
1. Πρώτη φορά: «Σύνδεση» › email › «Πρώτη φορά; Στείλε σύνδεσμο» › άνοιγμα συνδέσμου › ορισμός κωδικού.
2. Μετά: «Σύνδεση» › email + κωδικός. Η σύνδεση μένει ενεργή στη συσκευή μέχρι «Αποσύνδεση».

Η δωρεάν αποστολή email του Supabase έχει όριο 2 email την ώρα για όλη την εφαρμογή.
