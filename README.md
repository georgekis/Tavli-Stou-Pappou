# Τάβλι στου παππού

Εφαρμογή για το πρωτάθλημα τάβλι: πρόγραμμα, σκορ, βαθμολογία και πληρωμές.

- **Online:** https://tavli-stou-pappou.vercel.app
- **Βάση:** Supabase, project `tavli-stou-pappou`
- **Δημοσίευση:** κάθε push στο `main` ανεβαίνει αυτόματα στο Vercel.

## Αρχεία

| Αρχείο | Τι κάνει |
|---|---|
| `index.html` | Η δομή της σελίδας και τα παράθυρα επεξεργασίας |
| `css/styles.css` | Εμφάνιση |
| `js/config.js` | Σύνδεση με τη βάση, συμμετοχή ανά αγώνα |
| `js/supabase.js` | Ο client της βάσης |
| `js/state.js` | Κοινή κατάσταση και βοηθητικά |
| `js/data.js` | Φόρτωση, αποθήκευση, ζωντανή ενημέρωση |
| `js/stats.js` | Υπολογισμός βαθμολογίας και πληρωμών |
| `js/render.js` | Σχεδίαση των καρτελών |
| `js/dialogs.js` | Επεξεργασία αγώνων, αγωνιστικών, παικτών |
| `js/auth.js` | Σύνδεση γραμματείας με email |
| `js/main.js` | Εκκίνηση |

## Βαθμολογία

Νίκη = 1 βαθμός. Νίκη με τον αντίπαλο στο 0 = 2 βαθμοί. Οι τιμές αλλάζουν από την καρτέλα «Βαθμολογία» (μόνο η γραμματεία).
Ισοβαθμία: διαφορά πόντων, μετά πόντοι υπέρ.

## Δικαιώματα

Όλοι βλέπουν χωρίς σύνδεση. Αλλαγές κάνουν μόνο τα email του πίνακα `admins` στο Supabase.

## Τοπική δοκιμή

Τα αρχεία είναι ES modules, οπότε θέλουν server (όχι διπλό κλικ στο `index.html`).
Στο VS Code: επέκταση **Live Server** › δεξί κλικ στο `index.html` › *Open with Live Server*.
